Turning any web page into a level

The trick is that the browser already did the hard part. Lay the page out, ask every element where it ended up, paint those boxes and every single letter onto a canvas, then chop the canvas into little cells. Now the page is terrain.

for (const el of doc.body.querySelectorAll('*')) {
  const r = el.getBoundingClientRect();
  paint(r, getComputedStyle(el).backgroundColor);
}  // congratulations, your blog is now a platformer

Text becomes one-way ledges you can jump up through. Boxes and buttons are solid. Huge backgrounds turn into scenery so you're not trapped inside a hero banner.

Debris you can pick up and throw

Every explosion throws off particles that land and settle into rubble. Stand near a pile, press E, and the nearest hundred-ish cells squash into a rock over your head. Hold to wind up, let go to throw.

damage = (8 + cells * 0.42) * clamp(speed / 700, 0.5, 1.5)

Big rocks hit hard but fly slow. When one smashes it turns back into rubble, so the same debris keeps getting thrown around the whole match.

Keeping everyone's page identical

The server owns the terrain. Every change goes out as a tiny op, like "carve a circle here with this seed", and the server applies its own ops the same way every client does. Same ops, same order, same page, down to the last cell.

ops: [['c', x, y, r, seed, frac, power], ['b', cell, color, ...]]
